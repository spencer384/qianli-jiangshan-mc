# 江山千里 · 3D 方塊卷 (3D-Minecraft)

以 **Minecraft 體素方塊像素風格** 重構清代方琮《仿王希孟江山千里卷》的互動式 3D 山水長卷網頁專案（Three.js）。

## 特色
- **0.5 單位高密度體素地形**：使用 `InstancedMesh` 高效渲染青綠山水長卷。
- **32×32 `NearestFilter` 像素紋理**：沙地、赭石土、孔雀綠苔石、石青岩、青金石峰頂、木板、瓦片與像素水面。
- **方塊古建與自然生態**：5 層階梯屋簷民居、雙層亭閣拱橋、五層金頂佛塔、高桅帆船、松樹、竹林與柳樹。
- **動態與朦朧水嵐**：方塊飛瀑、過橋旅人、巡航木舟、振翅白鷺，以及湖面與山腰飄渺水氣薄霧。
- **互動式導覽**：支援 3D/長卷視圖切換、10 個經典分段飛鏡、自動導覽與像素小地圖拖曳。

## 本地執行
```bash
python -m http.server 8765
```
開啟瀏覽器瀏覽 `http://localhost:8765`。
